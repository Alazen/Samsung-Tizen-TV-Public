# Tizen doc lookup

## Start here

Read:
- docs/tizen/index.md
- docs/tizen/source-map.md

Then open only the official files listed for the task.

## Do not

- scan the whole vendored docs tree
- use .NET, Native, IoT, Wearable, or Mobile docs unless the task explicitly needs them
- edit files under docs/vendor
- assume Android adb behavior
- assume generic browser behavior applies to Tizen TV

## Output

Report:
- curated docs used
- official source files consulted
- relevant Tizen rule
- implementation impact
- uncertainty or missing docs
