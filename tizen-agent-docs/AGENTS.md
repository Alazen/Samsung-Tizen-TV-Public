# Agent instructions

This repository is a navigation harness for Samsung Tizen TV development docs.

Start here for every Tizen task:
- docs/tizen/index.md
- docs/tizen/source-map.md

Do not read the entire vendored Samsung docs tree.

Use docs/vendor/samsung-tizen-docs only when docs/tizen/source-map.md points to a specific official source.

Do not edit vendored docs except during an intentional upstream sync.

When answering or planning:
- name the curated docs used
- name the official source files consulted
- prefer Tizen TV Web Application docs over generic Tizen, .NET, Native, IoT, or Wearable docs
- stop if a task requires unsupported TV privileges, undocumented device behavior, signing secrets, or Samsung Seller Office-only information

Definition of done:
- answer is based on curated docs plus specific official sources
- uncertainty is stated explicitly
- no unrelated docs were scanned
