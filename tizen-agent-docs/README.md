# tizen-agent-docs

Navigation harness for Samsung Tizen TV web app documentation.

## Purpose

This repository helps small agents route quickly to the right Samsung/Tizen documentation without scanning the full upstream docs corpus.

## Start path for agents

1. `AGENTS.md`
2. `docs/tizen/index.md`
3. `docs/tizen/source-map.md`
4. One curated topic file in `docs/tizen/`
5. Only the mapped official source files in `docs/vendor/samsung-tizen-docs/`

## Current status

- Harness scaffold: ready
- Curated docs: ready
- Vendored official docs sync: pending network-enabled sparse sync (see `docs/vendor/samsung-tizen-docs/SNAPSHOT.md`)
