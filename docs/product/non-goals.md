# Non-Goals

- Implementing complete spatial navigation in this phase
- Rebinding mandatory remote keys (`ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Enter`, `Back`)
- Introducing runtime frameworks or dependencies
- Adding background service behavior (`serviceFile`)
- Shipping build outputs, packaged binaries, or generated artifacts
- Solving Tizen device-specific firmware quirks beyond soft-fail handling
