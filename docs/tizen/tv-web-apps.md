# Tizen TV web apps

Purpose:
Help agents create, inspect, package, and run Tizen TV web applications.

Read first:
- docs/tizen/source-map.md

Official sources:
- docs/vendor/samsung-tizen-docs/docs/application/web/get-started/tv/first-app.md
- docs/vendor/samsung-tizen-docs/docs/application/web/get-started/tv/first-samsung-tv-app.md
- docs/vendor/samsung-tizen-docs/docs/application/profiles/tv.md

Common tasks:
- identify app entry files and config.xml
- create a basic TV web app
- package a WGT
- install and launch on a TV or emulator
- choose TV profile guidance over generic profile guidance

Agent rules:
- do not treat a TV web app as a normal browser-only app
- do not assume mobile, wearable, .NET, or native Tizen guidance applies
- open only the official files listed above unless source-map.md routes elsewhere
- report package, launch, and device assumptions explicitly
