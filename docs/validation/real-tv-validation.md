# Real TV Validation

Real Samsung TV validation is the final acceptance gate.

## Procedure
1. Install and enable module through TizenBrew flow.
2. Validate remote navigation and focus behavior in real Stremio pages.
3. Validate media-key behavior during playback.
4. Validate back and exit handling.
5. Record pass/fail plus residual risks.

## Acceptance note
No feature is fully accepted until this real-device path is completed.
